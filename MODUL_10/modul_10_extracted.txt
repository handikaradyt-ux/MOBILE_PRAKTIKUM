Modul X - Desain GUI, Navigasi, dan Integrasi API dengan JSON Serialization di Flutter 
10.1. Ringkasan 
Komponen 
Uraian 
Tujuan Praktikum 
1. Mendesain antarmuka (GUI) aplikasi Flutter yang interaktif dan 
responsif. 
2. Menerapkan sistem navigasi antarhalaman menggunakan 
mekanisme named route. 
3. Membuat model data dengan JSON serialization dan 
deserialization. 
4. Mengintegrasikan data dari API eksternal ke dalam aplikasi 
menggunakan paket http. 
5. Menampilkan data hasil permintaan API ke layar aplikasi 
dengan tata letak yang rapi dan dinamis.
Dasar Teori 
Dalam pengembangan aplikasi Flutter, tiga konsep penting yang 
sering digunakan bersamaan adalah desain antarmuka (GUI), 
navigasi antarhalaman, dan manajemen data melalui model JSON. 
1. Desain GUI (Graphical User Interface) 
Flutter menyediakan kumpulan widget siap pakai untuk 
membangun antarmuka pengguna yang menarik. Widget seperti 
ListView dan Card sering digunakan untuk menampilkan data 
dengan tata letak yang rapi, terstruktur, dan mudah dibaca oleh 
pengguna. 
2. Navigasi dengan Named Route 
Navigasi merupakan mekanisme untuk berpindah dari satu 
halaman (screen) ke halaman lain dalam aplikasi. Dengan 
menggunakan named route, setiap halaman memiliki label unik 
(berupa string) yang didaftarkan di dalam MaterialApp, 
sehingga proses navigasi menjadi lebih terstruktur dan mudah 
dikelola. 
3. Model dan JSON Serialization 
JSON (JavaScript Object Notation) adalah format pertukaran 
data yang ringan dan mudah dibaca, serta banyak digunakan 
dalam komunikasi data melalui API. Dalam Flutter data sering 
kali dikirim atau diterima dalam format JSON. Oleh karena itu 
diperlukan proses serialization (mengubah objek Dart menjadi 
JSON) dan deserialization (mengubah JSON menjadi objek 
Dart). Dengan paket json_serializable, proses konversi dapat 
dilakukan secara otomatis melalui kode program yang 
dihasilkan oleh code generator yang dijalankan menggunakan 
perintah build_runner. 
4. Integrasi API 
Pada umumnya aplikasi mengambil data dari API eksternal 
menggunakan paket http. Data dalam format JSON yang 
diterima kemudian diubah menjadi model Dart, agar dapat 
digunakan dan ditampilkan pada antarmuka aplikasi.

- Flutter SDK (versi stabil terbaru) 
- Android Studio atau VS Code 
- Emulator Android / Perangkat fisik
