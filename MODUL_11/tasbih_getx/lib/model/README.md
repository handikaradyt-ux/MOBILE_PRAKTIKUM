# Folder Model

Folder ini disiapkan sesuai struktur modul (`model/`, `view/`, `viewmodel/`).
Pada Modul 11 (Tasbih Digital GetX), state dikelola langsung menggunakan variabel reaktif (`RxDouble` / `.obs`) di dalam `TasbihController`, sehingga belum mendefinisikan kelas model data entitas terpisah.
